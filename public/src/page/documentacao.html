Introdução

Bem-vindo à documentação oficial da DinoAtlas API. Esta é uma API RESTful pública e gratuita dedicada a fornecer dados precisos, estruturados e cientificamente validados sobre dinossauros e o mundo pré-histórico.

Inspirada em projetos open-source de referência, a DinoAtlas API oferece uma base de dados normalizada, permitindo consultas complexas por período geológico, localização, formação geológica e características físicas.

URL Base: https://dinoapi-swg8.onrender.com/api (ou /api em ambiente local).

Autenticação

A DinoAtlas API é totalmente aberta. Nenhuma chave de API (API Key) ou autenticação é necessária para realizar requisições. Basta fazer chamadas HTTP GET diretamente aos endpoints.

Dinossauros

O núcleo da API. Retorna dados detalhados sobre as 50+ espécies cadastradas, incluindo injeção automática de URLs de imagens e metadados.

Listar Todos os Dinossauros

GET /api/dinosaurs

Suporta paginação, busca textual e filtros combinados.

Buscar por ID

GET /api/dinosaurs/:id

Buscar Aleatório

GET /api/dinosaurs/random?limit=3

Atlas Geográfico

Recursos relacionais que permitem navegar pela base de dados através de localizações reais de descobertas paleontológicas.

Listar Continentes

GET /api/continents

Dinossauros por País

Retorna todos os dinossauros cujos fósseis foram encontrados em um país específico (ex: ID 16 = Brasil).

GET /api/countries/:id/dinosaurs

Dinossauros por Formação Geológica

Retorna todos os dinossauros associados a uma formação geológica específica (ex: ID 2 = Formação Morrison).

GET /api/formations/:id/dinosaurs

Entidades Relacionadas

Estes endpoints retornam listas de categorias que podem ser usadas como filtros na rota principal de dinossauros.

Recurso Endpoint Descrição
periods/api/periodsPeríodos geológicos (Triássico, Jurássico, Cretáceo)
diets/api/dietsTipos de alimentação (Carnívoro, Herbívoro, Onívoro)
families/api/familiesFamílias taxonômicas (Tyrannosauridae, Hadrosauridae, etc.)
museums/api/museumsMuseus que abrigam os holótipos ou espécimes principais

Filtros e Busca Avançada

A rota /api/dinosaurs aceita parâmetros de Query String para refinar os resultados. Múltiplos filtros operam com lógica aditiva (AND).

Parâmetro Tipo Descrição
searchStringBusca textual em nome, nome científico e descrição.
periodIdNumberFiltra pelo ID do período geológico.
countryIdNumberFiltra pelo ID do país de descoberta.
lengthMinNumberComprimento mínimo em metros.
weightMaxNumberPeso máximo em quilogramas.
sortStringCampo de ordenação: name, length, weight.
orderStringDireção: asc ou desc.

Exemplo de Filtro Combinado

Buscar carnívoros do Cretáceo com mais de 5 metros, ordenados do mais leve para o mais pesado:

/api/dinosaurs?dietId=1&periodId=3&lengthMin=5&sort=weight&order=asc

Exemplos de Código

JavaScript (Fetch API)

fetch('/api/dinosaurs?limit=1&countryId=16') .then(response => response.json()) .then(data => { // Data contém o array de dinossauros e metadados console.log(data.data[0].name); // Ex: "Irritator" }) .catch(error => console.error('Erro:', error));
