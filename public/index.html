Museu digital

Sobre a API: Simples, rápida e gratuita para todos.

Construída com foco em performance e precisão científica, a DinoAtlasAPI é uma ferramenta de código aberto que serve dados curados para projetos educacionais, sites informativos e aplicações mobile.

🔌

Rest api

Endpoints arquitetados seguindo os melhores padrões RESTful da indústria.

📦

Json database

Resposta em formato JSON estruturado, pronto para consumo imediato em qualquer stack.

🌍

Atlas Geográfico

Filtre dinossauros por continente, país e formação geológica (Novo v2.5).

🔓

Open source

Contribua com a base de dados no GitHub. Feito pela comunidade para a comunidade.

Endpoints populares

GET /api/dinosaurs Lista todos os dinossauros cadastrados 200 OK ›
GET /api/dinosaurs/random Retorna um ou mais dinossauros aleatórios 200 OK ›
GET /api/dinosaurs/:id Retorna detalhes de um dinossauro específico 200 OK ›
GET /api/continents Lista todos os continentes do Atlas 200 OK ›
GET /api/countries/:id/dinosaurs Lista todos os dinossauros de um país específico 200 OK ›
GET /api/formations/:id/dinosaurs Lista dinossauros de uma formação geológica 200 OK ›
