# 💻 Instalação

Siga os passos abaixo para rodar a DinoAtlasAPI no seu ambiente local.

## Pré-requisitos
Antes de começar, certifique-se de ter as seguintes ferramentas instaladas em sua máquina:
* **Node.js** (versão 18.x ou superior recomendada)
* **npm** (gerenciador de pacotes padrão do Node)

## Como Instalar Dependências
Clone o repositório oficial e instale os pacotes necessários:

```bash
git clone [https://github.com/Dferreiraz/DinoAtlasAPI.git](https://github.com/Dferreiraz/DinoAtlasAPI.git)
cd dinoatlasapi
npm install
```

Como Iniciar em Produção
Para iniciar a API em modo padrão:

```bash
npm start
```

Como Executar em Desenvolvimento
Para rodar a API com reinicialização automática ao salvar arquivos (utilizando nodemon ou similar):

```bash
npm run dev
```

Como Acessar Localmente
Por padrão, a API rodará na porta 3000. Você pode acessá-la através do seu navegador ou de clientes HTTP (como Postman ou Insomnia) utilizando a seguinte URL base:

http://localhost:3000
