# 🦖 Introdução

Bem-vindo à documentação oficial da **DinoAtlasAPI**. 

## O que é a DinoAtlasAPI
A DinoAtlasAPI é uma API RESTful pública e totalmente gratuita dedicada a fornecer dados precisos e estruturados sobre dinossauros e o mundo pré-histórico. Inspirada na simplicidade de projetos como a Api-Brazil, ela entrega informações de forma rápida e padronizada.

## Objetivo do Projeto
Fornecer uma base de dados centralizada, confiável e de fácil consumo sobre paleontologia para fins educacionais, acadêmicos e de entretenimento, eliminando a necessidade de raspar dados (web scraping) de múltiplas fontes.

## Público Alvo
* Desenvolvedores front-end e mobile buscando uma API pública para projetos de portfólio.
* Educadores e estudantes que necessitam de dados estruturados sobre dinossauros.
* Entusiastas da paleontologia.

## Filosofia do Projeto
* **Simplicidade:** Fácil de entender e integrar.
* **Organização:** Rotas semânticas e respostas padronizadas.
* **Open Source:** Mantida pela comunidade, para a comunidade.
* **Zero Configuração:** Sem necessidade de chaves de API (API Keys) ou autenticação complexa.

## Tecnologias Utilizadas
* **Node.js:** Ambiente de execução.
* **Express (ou framework similar):** Roteamento e middlewares.
* **JSON:** Armazenamento de dados estáticos atuando como banco de dados rápido e sem custos.

## Como a API é Organizada
A API segue o padrão REST. Os dados são consumidos via requisições HTTP e todas as respostas são formatadas em JSON. Os recursos são divididos em entidades principais (dinossauros) e entidades auxiliares (períodos, dietas, habitats).
